Головна ідея моделювання ER-моделі месенджера та у подальшому його реалізація та покращення.

Сутності моделі:

* User - користувач системи
* Attachment - файл який прикріпляється до повідомлення 
* Massage - повідомлення надіслане користувачем
* Conversation - чат користувачів 
* ConversationParticipant - участь користувачів у системі
